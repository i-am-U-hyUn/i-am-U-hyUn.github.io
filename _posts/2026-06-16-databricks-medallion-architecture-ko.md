오늘 처음으로 **Databricks**를 사용해봤다. 이론으로만 알던 것들을 직접 손으로 만져보니 느낌이 달랐다. 그 중 가장 인상 깊었던 개념이 **Medallion Architecture**였고, 그보다 더 오래 남을 것 같은 건 선배님이 해주신 한마디였다.

---

## Medallion Architecture란?

Medallion Architecture는 Databricks의 **Lakehouse** 환경에서 데이터를 계층적으로 관리하는 설계 패턴이다. 데이터가 각 레이어를 거치면서 품질이 점진적으로 개선되는 구조로, **"multi-hop architecture"** 라고도 불린다.

세 개의 레이어로 구성된다: **Bronze → Silver → Gold**

---

## Bronze Layer — 원본 데이터 (Raw)

> 외부 시스템에서 들어오는 데이터를 있는 그대로 저장하는 계층

- 소스 시스템의 테이블 구조를 그대로 반영
- 적재 일시, 프로세스 ID 등 메타데이터 컬럼 추가
- **목적**: 빠른 CDC(Change Data Capture), 이력 보관, 감사(Auditability), 재처리 가능성 확보

변환 없이 원본을 보존하기 때문에, 나중에 문제가 생겨도 항상 원점으로 돌아갈 수 있다.

---

## Silver Layer — 정제된 데이터 (Cleansed & Conformed)

> Bronze의 데이터를 "딱 필요한 만큼만" 정제해 Enterprise View를 만드는 계층

- 중복 제거, 표준화, 소스 간 매핑 처리
- 마스터 고객, 거래, 크로스 레퍼런스 테이블 등 구성
- **ETL이 아닌 ELT 방식**: 빠른 수집이 우선, 복잡한 변환은 Gold에서

| 특징 | 내용 |
|------|------|
| 데이터 모델 | 3rd Normal Form 스타일 |
| 사용자 | 부서별 분석가, 데이터 엔지니어, 데이터 사이언티스트 |
| 목적 | 셀프 서비스 분석, 고급 분석, ML의 원천 |

---

## Gold Layer — 비즈니스 레벨 데이터 (Curated)

> 실제 분석과 의사결정에 바로 쓸 수 있도록 가공된 최종 계층

- 프로젝트별 소비 목적에 맞게 구성된 DB
- **비정규화 + 읽기 최적화** 모델 (조인 최소화)
- Kimball 스타 스키마, Inmon 데이터 마트 방식이 주로 사용됨

고객 분석, 재고 분석, 제품 추천, 마케팅 분석 등 각 도메인에 특화된 결과물이 여기서 나온다.

---

## 계층 요약

```
외부 데이터 소스
       ↓
  🟫 Bronze (Raw) — 원본 보존, 빠른 수집
       ↓
  🥈 Silver (Cleansed) — 정제, 통합, Enterprise View
       ↓
  🥇 Gold (Curated) — 분석/ML 바로 사용 가능
```

---

## 가장 인상 깊었던 것 — "데이터를 직접 느껴라"

Databricks를 써보는 것도 흥미로웠지만, 오늘 선배님이 해주신 말씀이 더 오래 남을 것 같다.

> "AI가 데이터 분석을 많이 자동화해줬지만, 그렇다고 우리가 직접 데이터를 보지 않아도 되는 건 아니야. SQL로 직접 쿼리를 짜봐야 해."

신입 때는 특히 이게 중요하다고 하셨다.

- 설계 과정에서 소통하며 **"데이터를 느끼고"** 직관을 키우거나
- 컬럼명이나 약어만 보고도 **어떤 데이터인지 떠올릴 수 있게** 되거나
- 테이블 구조를 직접 확인하며 **데이터의 흐름을 이해하는 것**

이런 능력은 AI에게 맡긴다고 생기는 게 아니다. 직접 데이터를 보고, 실수도 하고, 고민하면서 쌓이는 것이다.

그리고 한 가지 더.

> "AI는 좋은 도구야. 하지만 도구일 뿐이지, 내 전부가 되어서는 안 돼."

자동화가 좋아질수록, 역설적으로 **그 자동화 결과를 제대로 검증할 수 있는 사람**의 가치가 높아진다고 생각한다. 쿼리를 직접 짤 줄 알아야 AI가 뱉어낸 결과가 맞는지 틀린지 판단할 수 있으니까.

---

## 마치며

오늘 Databricks를 통해 Medallion Architecture라는 데이터 설계의 큰 그림을 배웠다. Bronze에서 Gold로 흘러가는 데이터의 여정은, 어쩌면 내가 데이터를 다루는 방식과도 닮아있어야 하지 않을까.

처음엔 원본을 있는 그대로 받아들이고, 조금씩 이해를 쌓고, 결국 가치 있는 인사이트를 만들어내는 것.

직접 보고, 직접 써보고, 직접 느끼는 것에서 시작해야겠다.
