> 이 포스트는 [AWS 공식 블로그](https://aws.amazon.com/ko/blogs/korea/top-announcements-of-the-aws-summit-in-new-york-2026/)를 바탕으로, AWS Summit New York 2026의 주요 발표를 카테고리별로 정리한 글이다.

---

## 개요

2026년 AWS Summit New York에서는 **AI 에이전트** 중심의 대규모 발표가 쏟아졌다. 크게 ① 에이전트 구현, ② 보안, ③ 앱 개발, ④ 업무 자동화 네 가지 축으로 나눌 수 있으며, 인프라 레벨의 성능 개선도 함께 발표되었다.

---

## 1. 에이전트 구현을 위한 새로운 기능

### Amazon Bedrock AgentCore 신규 기능

AI 에이전트를 **조직 내부 데이터, 웹, 유료 지식**에 연결하는 기능이 추가되었다.

- 더 빠른 에이전트 구축 지원
- 에이전트 성능에 따라 확장 가능한 제어 적용
- 팀이 프로덕션 문제를 식별하고 수정하도록 지원

---

### Amazon Bedrock 관리형 지식 베이스

엔터프라이즈 **RAG(Retrieval-Augmented Generation) 파이프라인** 구축을 간소화하는 서비스다.

| 기능 | 설명 |
|------|------|
| 네이티브 데이터 커넥터 | 다양한 데이터 소스 연결 |
| 스마트 파싱 | 다중 형식 데이터 자동 준비 |
| 에이전트 리트리버 | 복잡한 다단계 쿼리 지원 |
| AgentCore Gateway 통합 | 게이트웨이와 연동 |

---

### Amazon Bedrock AgentCore 웹 검색

**완전관리형 웹 검색 도구**로, 에이전트가 최신 웹 지식을 바탕으로 인용된 응답을 제공한다.

- 보안 AWS 환경 내에서 동작 → 데이터 유출 방지
- 인프라 관리 불필요
- 개발자는 에이전트 구축에만 집중 가능

---

### AWS WAF AI 트래픽 수익 창출

콘텐츠 제공자가 **AI 봇 및 에이전트의 액세스에 대해 요금을 청구**할 수 있는 기능이다.

- AI 봇 트래픽에 가격 책정
- 타사 공급자의 결제 수락
- 엣지에서 범위 지정 액세스 권한 부여

---

### Amazon Bedrock AgentCore Harness 정식 출시

**몇 분 만에 프로덕션급 AI 에이전트**를 구축할 수 있는 서비스가 정식 출시되었다.

- 모델, 도구, 기술, 지침을 **구성(Configuration)** 으로 정의
- 오케스트레이션 루프 코딩 불필요 → 선언적 방식

---

### AWS Context (곧 출시 예정)

기존 데이터 간의 관계를 **자동으로 지식 그래프로 매핑**하는 서비스다.

- 에이전트 기반 검색 제공
- 런타임에 관리되는 데이터 관계 접근
- 비즈니스 규칙 및 도메인 지식 활용

---

## 2. 보안을 위한 새로운 에이전트 기능

### AWS Continuum (코드 취약성)

현재 **제한된 미리보기**로 제공 중이다.

- 환경 전반의 보안 조사 결과 수집
- 비즈니스 영향 기준 우선순위 자동 지정
- 악용 가능성 증명 및 자체 프로세스로 문제 해결

---

### AWS Security Agent

AWS Continuum의 일부로, 새로운 보안 기능이 다수 추가되었다:

| 기능 | 설명 |
|------|------|
| 위협 모델링 (미리보기) | STRIDE 프레임워크 기반 위협 식별 |
| PR 코드 스캐닝 | Git 플랫폼 전반의 pull 요청 스캔 |
| IDE 통합 | MCP를 통한 Kiro, Claude Code 플러그인 연동 |

> **핵심 가치:** 개발자가 컨텍스트 전환 없이 IDE 안에서 바로 보안 검토를 실행할 수 있다.

---

## 3. 앱 구현을 위한 새로운 에이전트 기능

### iOS용 Kiro (제한된 미리보기)

실제 엔지니어링 작업을 위해 구축된 **네이티브 iOS 앱**이다.

- 휴대폰에서 직접 Kiro 세션 시작, 모니터링, 조정
- 노트북 없이 세션 관리
- 변경 사항 검토 및 승인

---

### AWS DevOps 에이전트 릴리스 관리

프로덕션 배포 전 코드 변경을 **자율적으로 평가**하는 기능이다.

- 릴리스 준비 상태 자동 검토
- 프로덕션 유사 환경에서 자율 릴리스 테스트 실행

---

### AWS Transform (미리보기)

레거시 코드 리포지토리를 **지속적으로 현대화**하는 서비스다.

- 지속적 분석으로 코드 리포지토리 자동 스캔
- 구성 가능한 기준 적용
- 몇 주가 아닌 **몇 시간 만에** 조사 결과 생성
- 자율 수정 작업으로 **pull 요청 자동 생성**

---

## 4. 업무를 위한 새로운 에이전트 기능

### Amazon Q 자율형 에이전트

백그라운드에서 전문화된 에이전트를 생성해 반복 업무를 자동화한다.

**활용 예시:**
- **재무 에이전트**: 주문 접수 즉시 자동 처리
- **영업 에이전트**: CRM, 이메일, Slack을 모니터링해 후속 조치 계획 수립

---

### 새로운 활동 피드

이메일, 메시지, 캘린더, 작업을 **우선순위별로 통합**하여 보여준다.

- 빠른 응답이 필요한 메시지 자동 인식
- 사용자가 건너뛴 스레드 학습
- 주간 집중 주제 추적

---

## 5. 인프라 / 추가 발표

### Amazon S3 주석 (Annotations)

객체에 직접 연결되는 **풍부한 컨텍스트(최대 1GB)** 를 저장하는 기능이다.

- 검색 가능하고 변경 가능한 메타데이터
- AI 에이전트 및 자율 워크플로 지원
- 별도 메타데이터 시스템 구축 불필요

---

### Amazon ECS 자동 스케일링 속도 향상

고해상도(20초) 메트릭 지원으로 스케일링 속도가 크게 개선되었다:

| 지표 | 기존 | 개선 후 | 향상율 |
|------|------|--------|-------|
| 스케일 아웃 시간 | 363초 | 86초 | **76% 향상** |
| 전체 스케일링 시간 | 386초 | 109초 | **72% 향상** |

---

### Amazon EC2 G7 인스턴스

**NVIDIA RTX PRO 4500 Blackwell Server Edition GPU** 를 탑재한 새로운 인스턴스다.

| 성능 항목 | G6 대비 향상 |
|----------|------------|
| AI 추론 | **최대 4.6배** |
| 그래픽 | **최대 2.1배** |

- 6세대 Intel Xeon Scalable 프로세서 탑재

---

### Strands Agents (오픈소스)

프로덕션 에이전트 구축을 위한 **오픈소스 툴킷**으로, 세 가지 신규 기능이 추가되었다:

| 구성요소 | 기능 |
|---------|------|
| Harness SDK | 향상된 컨텍스트 관리 |
| Strands Shell | 격리된 실행 환경 |
| Strands Evals | 카오스 테스트 및 레드팀 기능 |

---

## 정리

AWS Summit New York 2026의 핵심 키워드는 단연 **"에이전트(Agent)"** 다. 단순한 AI 도우미를 넘어, 보안·개발·업무·인프라 전 영역에서 자율적으로 작동하는 에이전트 생태계를 구축하겠다는 AWS의 방향성이 뚜렷하게 드러났다.

특히 AgentCore Harness의 정식 출시와 AWS Context의 예고, 그리고 ECS/EC2 레벨의 성능 개선까지 아우르며, AI 에이전트를 **실제 프로덕션에서 쓸 수 있는 수준**으로 끌어올리는 데 집중하고 있음을 알 수 있다.
