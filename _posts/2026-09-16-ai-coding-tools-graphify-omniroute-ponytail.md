## 1. Graphify — 코드베이스를 지식 그래프로

```bash
uv tool install graphifyy      # 또는 pipx install graphifyy
graphify install               # AI 에이전트에 스킬 등록
```

한 줄로 설치하고 나면, 코딩 에이전트 안에서 `/graphify .` 한 번으로 지금 프로젝트 전체(코드+문서+PDF까지)를 **지식 그래프**로 만들어줘요. grep으로 파일 뒤지는 대신, "이 함수랑 저 함수는 어떻게 연결돼있어?" 같은 걸 그래프로 질의할 수 있는 게 핵심 포인트예요.

- 코드 파싱은 tree-sitter 기반 **로컬 처리**라서, 그냥 코드 구조 파악용으로만 쓰면 외부로 아무것도 안 나가요.
- 연결(edge) 하나하나에 `EXTRACTED`(원문에 명시)/`INFERRED`(추론) 태그가 붙어서, "이거 진짜 코드에 있는 관계야 아니면 추측이야?"를 구분할 수 있어요.
- 벡터 임베딩/vector store가 아니라 **진짜 그래프**라서 `graphify path A B`처럼 두 개념 사이 경로를 추적하는 것도 됩니다.
- 결과물이 `graph.html`(브라우저에서 바로 열리는 인터랙티브 그래프), `GRAPH_REPORT.md`(요약), `graph.json`(원본 데이터) 세 파일로 딱 떨어져 나와요.

YC(Y Combinator) S26 배치 소속 팀이 만든 프로젝트라 그런지 벤치마크 문서(BENCHMARKS.md)도 꽤 꼼꼼하게 공개돼 있어요.

## 2. OmniRoute — 무료 AI 게이트웨이

```bash
npm install -g omniroute
```

OmniRoute는 성격이 좀 달라요. 이건 코드를 분석하는 도구가 아니라, **여러 AI 모델 provider(Claude/GPT/Gemini/DeepSeek 등 300개 이상)를 하나의 엔드포인트로 묶어주는 게이트웨이**예요. Claude Code, Cursor, Codex 같은 코딩 에이전트가 이 게이트웨이를 통해서 모델을 호출하게 설정하면:

- provider별로 흩어진 **무료 티어를 자동으로 스택**해서 쓸 수 있게 해줘요(README 기준 월 약 14.7억 토큰 규모 무료 할당량을 카탈로그화).
- 특정 provider가 rate limit에 걸리면 다른 provider로 **자동 폴백**돼요.
- RTK + Caveman이라는 압축 기법으로 토큰 사용량을 15~95%까지 줄여준다고 홍보하고 있어요.
- MCP/A2A 프로토콜 지원, npm/Docker 양쪽으로 배포 가능.

MIT 라이선스 오픈소스고 Docker Hub/npm에 정식으로 올라와 있어요. 다만 "무료 티어를 긁어모아서 쓴다"는 컨셉 자체가 각 provider 이용약관과 미묘하게 걸칠 수 있는 부분이라(README에도 "일부 provider는 위험군으로 표시해뒀다"는 문구가 있어요), 회사 업무용 API 키를 물려서 쓰기보다는 개인 실험 용도로 먼저 써보시는 걸 추천드려요.

## 3. Ponytail — "제일 게으른 시니어 개발자"를 에이전트 안에

```bash
npm install -g @dietrichgebert/ponytail
```

이건 제가 오늘 제일 먼저 설치해본 건데, 컨셉이 재밌어요. "긴 머리 묶고, 안경 쓰고, 버전 관리보다 오래 회사 다닌 그 시니어 개발자"를 에이전트 페르소나로 넣어서, **과도한 설계를 못 하게 막는** 스킬이에요.

동작 원리는 "사다리"예요 — 코드를 짜기 전에 이 순서로 먼저 확인하게 시킵니다.

```
1. 이게 진짜 필요한가?     → 아니면 안 만든다 (YAGNI)
2. 이미 코드베이스에 있나?  → 재사용
3. 표준 라이브러리로 되나?  → 그거 쓴다
4. 네이티브 플랫폼 기능?    → 그거 쓴다
5. 이미 설치된 의존성?      → 그거 쓴다
6. 한 줄로 되나?           → 한 줄로
7. 그래도 안 되면: 필요한 최소한만
```

예시가 재밌었어요 — 날짜 선택기(date picker) 하나 만들어달라고 하면, 보통 에이전트는 `flatpickr` 라이브러리 설치하고 래퍼 컴포넌트 만들고 타임존 얘기까지 꺼내는데, ponytail을 쓰면 그냥:

```html
<input type="date">
```

이렇게 끝내버려요. 실제 FastAPI+React 오픈소스 레포에 에이전트가 기능 12개를 구현하게 시킨 벤치마크에서 코드 줄 수 -54%, 토큰 -22%, 비용 -20%, 시간 -27% 줄었다고 하고, 안전성(validation/에러 처리/보안 등 안 빼먹는지)은 100% 유지했다고 해요. 저는 지금 이 프로젝트(architect_draw_ai)에 이미 설치해서 쓰고 있어요.

## 셋을 한 줄로 요약하면

| 도구 | 뭘 하는 도구인가 | 이런 분께 |
|---|---|---|
| **Graphify** | 코드베이스를 지식 그래프로 만들어 질의 | 큰 레포에서 구조 파악·온보딩이 힘드신 분 |
| **OmniRoute** | 여러 AI provider를 하나의 게이트웨이로 | 여러 모델을 테스트/비교하며 비용 아끼고 싶으신 분 |
| **Ponytail** | 에이전트가 과도하게 설계하는 걸 막음 | "AI가 짠 코드가 항상 너무 거창하다" 느끼신 분 |

셋 다 설치 자체는 1~2분이면 끝나서 가볍게 하나씩 써보시길 추천드려요. 저는 이 중에서 개인적으로는 Ponytail이 제일 체감이 컸어요 — 평소 에이전트가 간단한 요청에도 이것저것 붙이려는 습관이 있었는데, 딱 필요한 만큼만 짜주니까 리뷰할 것도 줄더라고요.
