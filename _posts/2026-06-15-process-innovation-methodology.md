## 들어가며

경영전략 수립과 더불어 **프로세스 혁신(Process Innovation, PI)**은 가장 인기 좋은 컨설팅 영역 중 하나다.
PI를 이해하려면 먼저 "프로세스란 무엇인가", "혁신이란 무엇인가"부터 짚고 가야 한다.

---

## 1. 프로세스(Process)란?

### SIPOC 개념

6-시그마 관점에서 프로세스를 표현하는 **SIPOC** 프레임워크가 있다.

| 구분 | 영문 | 의미 |
|---|---|---|
| S | Supplier | 공급자 |
| I | Input | 투입 |
| P | Process | 프로세스 |
| O | Output | 산출 |
| C | Customer | 고객 |

> SIPOC는 신사업 개발 프레임워크로도 활용되며, 프로세스를 규명하는 데 매우 유용한 개념이다.
{: .prompt-info }

프로세스는 산업·업종에 따라 정의가 달라질 수 있지만, 공통 원칙은 다음과 같다.
- **시작과 끝이 명확**할 것
- **독립적**일 것
- **의미 있는 산출물 단위**로 구분할 것

### 업무-기능 모델 (Function-Process Model, FP 모델)

경영전략 컨설팅에서는 Value Chain 분석이나 공급 사슬 분석도 하지만, 실무에서는 **FP 모델**을 더 많이 사용한다.

FP 모델의 계층 구조는 다음과 같다.

```
기능 (Function)
 └── 프로세스 (Mega Process / Process)
      └── 하위 프로세스 (Sub Process)
           └── 기본 프로세스 / 기본 활동 (Elementary Process / Activity)
```

| 구분 | 설명 | 예시 |
|---|---|---|
| **기능** | 관련 업무를 유기적으로 묶은 집합. 실행력은 없으나 Value Chain의 기본 단위 | 생산관리, 연구개발, 영업 |
| **프로세스** | 실행 가능한 업무 활동 단위. 여러 부서를 거쳐 수행 | 기준정보 관리, 조직 관리, 품질 검사 |
| **하위 프로세스** | 프로세스의 구성 요소 | — |
| **기본 프로세스/활동** | 한 사람이 한 장소에서 완수하는 업무 최소 단위. FP 모델의 근간 | — |

### 프로세스 정의서

구조화가 끝나면 **프로세스 정의서**를 작성한다. 3가지로 구성된다.

1. **프로세스 구성도** — 전체 프로세스를 한눈에 볼 수 있도록 상호 연결 표시
2. **프로세스 흐름도** — 하위 프로세스 간 관계, 수작업·자동화 구분, 승인/검토 분기, Trigger Point 표기
3. **프로세스별 상세 설명** — 각 Activity의 수행 방법, 지침, 원칙, 입출력 관계, 수행 주체, 측정지표 등

> FP 모델과 프로세스 정의서 작성은 상당한 시간과 노력이 필요하다. 단순 커뮤니케이션이 목적이라면 다른 도구를 고려하는 것이 더 효율적일 수 있다.
{: .prompt-warning }

## 2. 혁신(Innovation)이란?

### 혁신의 정의

다양한 기관과 학자들이 혁신을 정의했다.

| 출처 | 정의 |
|---|---|
| Wikipedia | "the process of making improvements by introducing something new" |
| American Heritage Dictionary | "the act of introducing something new or something newly introduced" |
| Merriam Webster | "the introduction of something new; new idea, method, or device" |
| **Peter Drucker** | "change that creates new dimension of performance" |

공통 키워드: **change**, **introduction**, **new**

> 혁신의 본질 = **"새로운 것의 도입, 또는 그것으로 인한 변화"**
{: .prompt-tip }

### 기업이 혁신하는 이유

슘페터(Joseph Schumpeter, 1883~1950)는 혁신의 동기를 이렇게 설명했다.
- 새로운 **재화** 도입
- 새로운 **생산 방식** 적용
- 새로운 **시장** 개척

결국 혁신은 **더 많은 경제적 부(富) 창출**, 즉 **기업의 가치 창출**과 직결된다.
오늘날에는 가치 창출을 넘어 **생존을 위한 혁신**의 차원에 이른다.

> "강한 자가 살아남는 것이 아니라, 살아남는 것이 강한 자다."

## 3. 다양한 경영혁신 방법론

1990년대 이후 경영혁신 기법이 다양화되었다. 주요 기법들의 특징을 비교하면 아래와 같다.

| 기법 | 기원 | 특징 |
|---|---|---|
| **TPS** (Toyota Production System) | 일본 | 낭비 제거, 린(Lean) 생산 |
| **6-시그마** | 미국 (모토롤라 → GE) | 품질 중심, 통계적 접근, DMAIC |
| **TOC** (Theory of Constraints) | — | 병목 제거 중심 |
| **BPR** (Business Process Reengineering) | — | 프로세스 근본적 재설계 |
| **PI** (Process Innovation) | — | IT 기반 프로세스 재설계 |

## 4. PI 방법론

### PI란?

> 사업을 보다 효율적이고 수익성 높게 수행하고 고객에게 더 나은 서비스를 제공하기 위해 **정보기술(IT)을 이용해서 프로세스를 재설계**하는 것

### 프로세스 혁신 vs 프로세스 개선

| 구분 | 프로세스 혁신 (PI) | 프로세스 개선 |
|---|---|---|
| 범위 | 전사적, 근본적 재설계 | 부분적, 점진적 개선 |
| 방향 | Top-Down | Bottom-Up |
| 기간 | 장기 | 단기 |
| 변화 정도 | 급진적 | 점진적 |

PI는 **산업 성장기·성숙기** 기업에서 가장 큰 성과를 얻기 쉽다.

### PI 추진 방식: 패키지 vs In-house 개발

| 구분 | 패키지 중심 (SAP, Oracle 등) | 프로세스 중심 (In-house 개발) |
|---|---|---|
| **방향** | Top-Down | Top-Down + Bottom-Up |
| **장점** | 글로벌 표준 도입, 빠른 구축 | 기업 맞춤형 최적화 |
| **단점** | 라이선스 비용 과다 | 글로벌 표준과 멀어질 수 있음, 운영·유지보수 복잡 |

> 최근에는 **클라우드 기반 SaaS 형태의 ERP**도 확산 중이다.
{: .prompt-info }

## 5. PI vs 6-시그마 비교

| 구분 | PI | 6-시그마 |
|---|---|---|
| **목적** | 구조적 개선 기반 조성 | 특정 프로세스 품질의 지속적 개선 |
| **방식** | 일회적, 전사적 | 반복적, 특정 프로세스 중심 |
| **기간** | 중장기 | 단기 |
| **접근** | IT 기반 재설계 | 통계적 품질 관리 |

두 기법을 **연계**하여 사용하기도 한다.
- 중장기 과제 → **PI**
- 단기 과제 → **6-시그마**

---

## 마치며

PI와 6-시그마의 붐이 다소 수그러든 편이지만, **제4차 산업혁명**과 **IoT 기반 확산**으로 조만간 PI 영역이 다시 주목받을 것으로 예상된다. 로봇·AI 도입으로 전통적인 제조·운영 프로세스가 완전히 바뀌고 있기 때문이다.

경영혁신은 기업이 존재하는 한 계속될 컨설팅 테마다.
