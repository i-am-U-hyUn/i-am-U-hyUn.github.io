---

## 왜 대시보드 디자인이 중요한가?

데이터는 아무리 정확해도 전달이 안 되면 의미가 없다. 대시보드는 단순히 숫자를 보여주는 도구가 아니라, 조직의 **브랜드 아이덴티티**와 **신뢰**를 반영하는 커뮤니케이션 도구다.

Databricks AI/BI 대시보드는 글꼴, 색상, 레이아웃을 세밀하게 커스터마이징할 수 있어 조직 전체에 일관된 시각적 경험을 제공할 수 있다.

---

## 1. 최종 사용자에 맞는 레이아웃 설계

좋은 대시보드는 **사용자가 누구인가**에서 출발한다.

### 그리드 열 수 선택

| 열 수 | 적합한 대상 | 특징 |
|---|---|---|
| **3열** | 임원, 경영진 | 핵심 지표 중심, 깔끔하고 단순 |
| **4열** | 일반 비즈니스 사용자 | 균형 잡힌 정보량 |
| **6열** | 데이터 분석가, 기술직 | 상세 정보, 복잡한 시각화 |

### 시선 흐름 고려하기

사람의 눈은 화면을 읽을 때 **Z자** 또는 **F자** 패턴으로 움직인다.

- 가장 중요한 KPI는 **좌상단**에 배치
- 상세 차트나 보조 정보는 **하단**으로 배치
- 핵심 요소는 **크게**, 보조 요소는 **작게** 표시해 시각적 계층 구조를 만든다

---

## 2. 글꼴 선택

대시보드 글꼴은 가독성이 최우선이다.

### 권장 글꼴 유형

**산세리프(Sans-serif) 글꼴**을 사용하는 것이 좋다.

- Arial
- Tahoma
- Verdana

이 글꼴들은 화면에서 작은 크기에도 잘 읽히고, 깔끔한 인상을 준다.

### 브랜드 일관성을 위한 로컬 글꼴

Databricks AI/BI는 **로컬 글꼴 추가**를 지원한다. 회사 브랜드 폰트를 그대로 적용할 수 있어 사내 대시보드도 브랜드 가이드라인을 완벽히 따를 수 있다.

### 대비(Contrast) 설정

텍스트 가독성을 위해 배경과 글꼴 색의 대비를 충분히 확보해야 한다.

| 배경 색상 | 권장 글꼴 색상 |
|---|---|
| 밝은 배경 `#EBEBEB` | 어두운 텍스트 `#08141A` |
| 어두운 배경 `#08141A` | 밝은 텍스트 `#FCFCFD` |

---

## 3. UI 색상 정의 — 60-30-10 규칙

색상을 무작정 쓰면 대시보드가 산만해진다. **60-30-10 규칙**을 적용하면 시각적으로 안정된 구성을 만들 수 있다.

| 비율 | 역할 | 적용 위치 |
|---|---|---|
| **60% 주조색** | 배경 | 캔버스, 위젯 배경 |
| **30% 보조색** | 내용 | 글꼴, 시각화 팔레트 |
| **10% 강조색** | 인터랙션 | 버튼, 필터, 대화형 요소 |

### 무채색(Neutral) 팔레트 예시

**라이트 모드:**

```
캔버스 배경: #EBEBEB
위젯 배경:  #FCFCFD
```

**다크 모드:**

```
캔버스 배경: #1E343F
위젯 배경:  #08141A
```

---

## 4. 시각화 팔레트 설계

차트와 그래프에 사용할 색상 팔레트는 **색맹 친화적(Colorblind-friendly)** 설계가 필수다.

### 팔레트 구성 원칙

- 5~9가지 색상을 사용 (너무 많으면 혼란, 너무 적으면 구분 불가)
- **Adobe Color** 등의 색맹 시뮬레이터로 반드시 검증
- 색상만으로 정보를 구분하지 말고, 모양·패턴·라벨도 함께 활용

### 팔레트 예시

아래는 색맹 친화적으로 설계된 팔레트 예시다:

| 색상 코드 | 용도 |
|---|---|
| `#15AFDD` | 주요 데이터 계열 1 |
| `#2375A8` | 주요 데이터 계열 2 |
| `#52A870` | 긍정/증가 지표 |
| `#C85070` | 부정/감소 지표 |
| `#C89930` | 경고/중립 지표 |

---

## 5. 워크스페이스 테마로 전사 일관성 유지

개별 대시보드마다 디자인을 설정하는 것은 비효율적이다. Databricks는 **워크스페이스 테마** 기능을 제공한다.

> **워크스페이스 테마를 한 번만 설정하면, 해당 워크스페이스의 모든 대시보드에 자동으로 테마가 반영된다.**

이를 통해:

- 조직 전체 브랜드 일관성 자동 유지
- 새 대시보드마다 스타일을 다시 설정할 필요 없음
- 관리자 한 명이 전사 디자인 기준을 통제 가능

---

## 실전 예시 — Wanderbricks 브랜드 대시보드

원문에서는 **Wanderbricks**라는 가상 기업의 브랜드를 기반으로 대시보드를 설계하는 사례를 제시한다.

브랜드 색상을 정의하고 → 60-30-10 규칙 적용 → 색맹 시뮬레이터 검증 → 워크스페이스 테마 등록 순서로 진행한다. Genie Code 프롬프트를 활용해 테마 설정 코드를 자동 생성하는 방법도 소개한다.

---

## 정리 — 아름다운 대시보드를 위한 체크리스트

| 항목 | 확인 |
|---|---|
| 사용자 유형에 맞는 그리드 열 수 선택 | ✅ |
| Z/F자 시선 흐름에 맞는 KPI 배치 | ✅ |
| 산세리프 글꼴 + 충분한 대비 확보 | ✅ |
| 60-30-10 색상 규칙 적용 | ✅ |
| 색맹 친화적 시각화 팔레트 검증 | ✅ |
| 워크스페이스 테마 등록으로 전사 일관성 유지 | ✅ |

데이터의 신뢰성은 분석 품질에서, **데이터의 설득력은 디자인**에서 온다. 오늘 소개한 원칙들을 적용하면 보고서급 퀄리티의 대시보드를 Databricks 안에서 바로 만들 수 있다.
